# A Little Piece of Happiness

A handmade-paper / scrapbook-inspired birthday website built with HTML, CSS and vanilla JavaScript. It is responsive for phones, tablets and desktop screens.

## Personalise before sharing
1. Open `script.js` and change `CONFIG.name` to her first name.
2. Replace the four sample photos in `assets/photos/` with your own files named `photo1.jpg` through `photo4.jpg`.
3. Optionally add an audio file named `birthday.mp3` to `assets/music/`.
4. Open `index.html` in a browser and test the full experience, especially on a phone.

## Run locally
Double-click `index.html`, or use VS Code Live Server.

## Deploy
Deploy the folder to Netlify or Vercel as a static site. No backend or build command is required.

## Included interactions
- Gift-opening intro
- Three personal "open when" notes
- Animated startup workflow with success and rocket launch
- Interactive candles
- Optional background music

The sample photo tiles show placeholders until you add your own images. Music is user-initiated because browsers generally block autoplay.
